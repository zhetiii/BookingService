# BookingService — Микросервисная система бронирования

Проект представляет собой микросервисную архитектуру на базе **.NET 8**, **Docker Compose** и **PostgreSQL**.

## Архитектура системы
- **`booking-service`** (порт `8080`): CRUD бронирований, работа с PostgreSQL, отправка HTTP-уведомлений.
- **`user-service`** (порт `8081`): Сервис профилей пользователей.
- **`notification-service`** (порт `8082`): Прием и хранение истории уведомлений.
- **`db`** (PostgreSQL 16, порт `5432`): Хранение данных с volume `db_data`.

## Запуск
```bash
docker compose up -d --build
